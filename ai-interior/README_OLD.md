# AI 인테리어 시스템 통합 가이드

## 📋 프로젝트 개요

이 프로젝트는 eunbi(3D 방 설계)와 minah(AI 이미지 생성) 시스템을 통합하여, MongoDB에 저장된 방 좌표 데이터를 활용해 일관성 있는 AI 인테리어 이미지를 생성하는 시스템입니다.

### 🏗️ 시스템 아키텍처

```
[eunbi 3D Editor] 
    ↓ (방 좌표 데이터)
[MongoDB] 
    ↓ 
[minah FastAPI] 
    ↓ (레이아웃 분석)
[Dify RAG System] ← 성공 사례 학습
    ↓ (최적화된 프롬프트)
[AI Image Generation] 
    ↓
[Generated Image] → 사용자 피드백 → [Dify Knowledge Base]
```

## 🚨 현재 시스템의 문제점

### 1. 좌표 인식 문제
- **텍스트 기반 위치 서술**: "in the bottom-right corner", "against the left wall"
- **부정확한 해석**: AI가 정확한 수치 좌표를 이해하지 못함
- **일관성 부족**: 같은 설명이라도 매번 다른 위치에 배치

### 2. 이미지 일관성 부족
- **스타일 변동**: 매번 다른 색상, 구도, 조명
- **가구 크기 불일치**: 비현실적인 비율과 크기
- **레이아웃 재현 실패**: 정확한 가구 배치 구현 어려움

## 💡 Dify 기반 해결책

### 왜 Dify를 선택했는가?

| 구분 | 자체 구현 | **Dify 활용** |
|------|-----------|---------------|
| 개발 시간 | 4주 | **1주** |
| 임베딩 품질 | 직접 구축 필요 | **전문 모델 제공** |
| 벡터 DB | ChromaDB 설정 | **내장 (Qdrant/Pinecone)** |
| 학습 시스템 | 별도 구축 필요 | **RAG 기본 제공** |
| 확장성 | 수동 관리 | **Auto-scaling** |
| 유지보수 | 복잡 | **관리형 서비스** |

## 🎯 통합 전략

### Phase 1: 기본 연동 (1주)
1. **Dify 계정 설정** - RAG 앱 생성
2. **Knowledge Base 구축** - 방 레이아웃 데이터 저장
3. **기본 API 통합** - 유사 레이아웃 검색
4. **프롬프트 최적화** - 일관된 이미지 생성

### Phase 2: 피드백 시스템 (1주)
1. **사용자 평가 UI** - 별점 및 코멘트 수집
2. **자동 학습** - 좋은 결과를 Knowledge Base에 축적
3. **A/B 테스트** - Dify vs 기존 방식 성능 비교

### Phase 3: 고도화 (2주)
1. **Workflow 구성** - 전체 파이프라인 자동화
2. **실시간 학습** - 즉시 피드백 반영
3. **다양한 스타일** - 모던, 클래식, 미니멀 등

## 📊 예상 개선 효과

- **개발 시간**: 4주 → **1주** (75% 단축)
- **사용자 만족도**: 3.2/5 → **4.5/5** 예상
