# 방 크기 측정기 (Room Size Analyzer)

방 사진을 업로드하면 방의 크기(가로, 세로, 면적)를 자동으로 측정해주는 웹 애플리케이션입니다.

## 기능

- 이미지 업로드 (드래그 앤 드롭 지원)
- 방의 가로, 세로 길이 자동 측정
- 면적 계산 (제곱미터)
- 반응형 웹 디자인 (모바일 지원)

## 설치 및 실행 방법

### 1. 필요한 패키지 설치

```bash
# 백엔드 디렉토리로 이동
cd /home/node1/final_project/room-analyzer-2/backend

# 필요한 Python 패키지 설치
pip install -r requirements.txt
```

### 2. 애플리케이션 실행

```bash
# 백엔드 서버 실행
python app.py
```

### 3. 웹 브라우저에서 접속

웹 브라우저를 열고 다음 주소로 접속하세요:
```
http://localhost:5000
```

## 사용 방법

1. 웹 페이지에 접속합니다.
2. "이미지를 드래그 앤 드롭하거나 클릭하여 업로드하세요" 영역을 클릭하거나 이미지를 드래그 앤 드롭합니다.
3. "측정 시작" 버튼을 클릭합니다.
4. 잠시 후 측정 결과가 표시됩니다.

## 기술 스택

- **백엔드**: Python, Flask, OpenCV
- **프론트엔드**: HTML5, CSS3, JavaScript (Vanilla JS)
- **배포**: 로컬 호스트 (Flask 개발 서버)

## 주의사항

- 측정 결과는 참고용이며, 실제와 다를 수 있습니다.
- 정확한 측정을 위해서는 정면에서 촬영된 사진을 사용하세요.
- 천장과 바닥이 잘 보이는 사진을 사용하면 더 정확한 결과를 얻을 수 있습니다.
